Tributary is a Node.js command-line tool published on npm.

## Requirements

| Requirement | Version |
| --- | --- |
| Node.js | 22.12 or later |
| Source database | PostgreSQL |
| Target database | PostgreSQL |
| Operating system | macOS, Linux, or Windows |

Check your Node.js version:

```bash
node --version
```

## Install the CLI

<CodeGroup>

```bash npm
npm install -g @bhuneshvar-k/tributary
```

```bash pnpm
pnpm add -g @bhuneshvar-k/tributary
```

```bash yarn
yarn global add @bhuneshvar-k/tributary
```

</CodeGroup>

This installs the `tributary` command globally.

### Run without installing

You can also run Tributary on demand with `npx`:

```bash
npx @bhuneshvar-k/tributary --help
```

## Verify the installation

```bash
tributary --version
tributary --help
```

You should see the version number and a list of commands: `inspect`, `plan`, `sync`, `schema`, `config`, and `ai`.

## Install the library

To use the engine from your own TypeScript or JavaScript code, install the core package instead:

```bash
npm install @bhuneshvar-k/tributary-core
```

See [Use as a library](/library) for details.

## Upgrade

Re-run the install command to get the latest version:

```bash
npm install -g @bhuneshvar-k/tributary@latest
```

## Uninstall

```bash
npm uninstall -g @bhuneshvar-k/tributary
```

Your settings live in a separate file and are not removed. Run `tributary config path` before uninstalling to find it, then delete it if you no longer need it. See [Configuration](/configuration#where-settings-are-stored).

<Note>
  Upgrading from the older Go version (now archived as `tributary-go`)? The TypeScript version is a different tool with a new command set. Connections live in a config file instead of DSN flags, and checkpoints live in the target database instead of a local SQLite file.
</Note>
